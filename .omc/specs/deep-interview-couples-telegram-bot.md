## Goal
Telegram-бот на Python — единый «хаб пары»: два человека объединяются в пару по ссылке-приглашению и ведут в личных чатах с ботом общий календарь, список идей «куда сходить», поручения друг другу с мгновенными уведомлениями, список покупок, важные даты и личные списки желаний-подарков; бот сам напоминает о предстоящем по понятным дефолтным правилам. v1 = все 8 блоков работают end-to-end.

## Constraints
- Python; классический чат-бот: inline-кнопки, меню, команды. Без Telegram Mini App и внешнего фронтенда.
- Бот работает только в личных чатах партнёров; уведомления второму партнёру доставляются в его личный чат с ботом.
- Один часовой пояс на пару, задаётся при создании пары.
- Пользователь состоит максимум в одной паре.
- Язык интерфейса: русский.
- Хранение: локальная БД (SQLite достаточно для v1); один процесс, планировщик напоминаний внутри приложения (например, aiogram/python-telegram-bot + APScheduler).
- Напоминания: фиксированные дефолты, опционально своё время при создании элемента. Без глобальных пользовательских настроек в v1.

## Non-Goals
- Telegram Mini App / веб-интерфейс.
- Групповой чат-режим.
- Бронь подарков, скрытые желания, уведомления о просмотрах.
- Еженедельный дайджест.
- Совместный бюджет (не выбран при расширении топологии).
- Индивидуальные часовые пояса, мультиязычность, масштаб «на всех» — v1 для реальных пар, но без амбиций высоконагруженного сервиса.

## Acceptance Criteria
- [ ] А запускает бота → «Пригласить» → получает ссылку `t.me/<bot>?start=<код>`; Б открывает её, подтверждает → пара создана, оба получают подтверждение; при создании задаётся часовой пояс пары.
- [ ] Повторное использование кода/попытка третьего человека вступить в существующую пару отклоняется с понятным сообщением.
- [ ] Событие календаря: создание с датой/временем через кнопки; видно обоим; напоминание обоим за день и за 2 часа (в поясе пары); при создании можно задать своё время напоминания.
- [ ] Вишлист-идея: добавляется без даты, видна обоим; идею можно превратить в событие календаря, указав дату.
- [ ] Поручение: А создаёт поручение с опциональным дедлайном → Б мгновенно получает сообщение с кнопками «Принять»/«Не могу» → после выполнения жмёт «Готово»; А получает уведомление о каждой смене статуса; при просрочке дедлайна повторное напоминание обоим; поручение с дедлайном напоминает исполнителю в день дедлайна.
- [ ] Список покупок: любой из пары добавляет позиции и отмечает «куплено»; список общий.
- [ ] Важная дата: создаётся с ежегодным повтором; напоминание обоим за неделю и в день.
- [ ] Желания-подарки: каждый ведёт свой список; партнёр может открыть список другого только на чтение; владельцу не сообщается о просмотрах.
- [ ] Главное меню с inline-кнопками даёт доступ ко всем 8 блокам; календарь отображается сеткой месяца из inline-кнопок.
- [ ] Все времена интерпретируются и показываются в часовом поясе пары.
